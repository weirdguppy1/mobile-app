# Roommate Match

A Tinder-style mobile app that helps college students find their roommate.
React Native + Expo + Expo Router + TypeScript.

See [AGENTS.md](./AGENTS.md) for architecture and conventions, and
[DESIGN.md](./DESIGN.md) for the design system.

## Develop

```bash
pnpm install
pnpm start      # then open in Expo Go, or:
pnpm ios        # build & run the iOS dev client
pnpm android    # build & run the Android dev client
```
